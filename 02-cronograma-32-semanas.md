Este documento NÃO é estático. Foi feito pra evoluir com o projeto e com as mudanças do mercado digital de 2026.

## Quando atualizar (obrigatório)

A cada 2 semanas, na primeira segunda-feira disponível, fazer revisão completa olhando:

### 1. Mudanças no projeto
- [ ] Marcas prioritárias mudaram? (hoje: Fluidra + Syllent)
- [ ] Fase atual do projeto mudou? (porta de entrada → expansão → aprofundamento → maturidade)
- [ ] Tickets praticados mudaram?
- [ ] Novos produtos lançados?
- [ ] Status da negociação Fluidra mudou? (impacto direto no cronograma)

### 2. Mudanças no mercado/algoritmo
- [ ] Algoritmo do Instagram/YouTube/TikTok mudou (testar formatos novos)?
- [ ] Surgiu novo concorrente relevante no nicho?
- [ ] Nova plataforma ganhou tração (ex: Threads, BlueSky, novos canais)?
- [ ] Novas tendências de formato (ex: vídeo carrossel, podcast curto, lives específicas)?

### 3. Mudanças nos dados de performance
- [ ] Quais vídeos performaram MELHOR que o esperado? (replicar fórmula)
- [ ] Quais vídeos performaram PIOR? (analisar e corrigir)
- [ ] CTR de thumbnails está acima ou abaixo de 5%?
- [ ] Retenção média está acima ou abaixo de 50%?
- [ ] Conversão de leads (vídeo → grupo WhatsApp) está crescendo?

### 4. Mudanças no mercado de piscina
- [ ] Novos equipamentos lançados pela Fluidra ou Syllent?
- [ ] Nova regulamentação ou norma técnica?
- [ ] Sazonalidade está confirmando (alta out-fev / baixa jun-set)?
- [ ] Surgiram dúvidas novas e recorrentes da audiência?
